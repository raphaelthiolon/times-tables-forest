PRIVATE DANCE CLIP (personal use only)

Put one audio file here named:  dance.mp3   (or dance.m4a, dance.ogg, dance.wav)

What happens: during the dance break (every 5 right answers in a row), the game plays
this clip instead of the built-in jingle. The dance lasts about 5 seconds, so use a clip
trimmed to that length, starting at the part you want.

Rules:
- Use only music you have the right to use (for example your own purchased copy), on your
  own devices.
- NEVER publish this folder. If the game is put on a public web host, delete this folder's
  audio files first. Hosting copyrighted songs publicly is copyright infringement.
- If no file is here, the game plays its original jingle. Nothing breaks.
